## 🚀 On-going Projects

### ⚙️ Cross-Platform Dotfiles

A structured dotfiles management system for reproducibly configuring Linux and
Windows development environments.

- Managed personal configuration files using `chezmoi`.
- Created separate bootstrap workflows for Unix and Windows.
- Added profile-based package installation for core, development, and desktop environments.
- Supported Bash and PowerShell automation.
- Separated user configuration from privileged system configuration.
